# TimeFlew website

Standalone static site. Developer: Tridip Choudhury. Contact: tridipchoudhury88@gmail.com.

## Publish at https://timeflewapp.github.io/

1. Create or use a GitHub organization (or personal account) named `timeflew`. Your existing `tridipchoudhury` account can own the organization. Availability has not been verified.
2. Under that owner, create a public repository named `timeflewapp.github.io`.
3. Push this folder's contents to the root of its `main` branch.
4. Repository Settings → Pages → Deploy from a branch → main → / (root). Enable HTTPS.
5. Verify Home, About, Privacy and Support on the published site before using the URLs in store submissions.

A GitHub Pages organization site uses the organization name in its address. This repository belongs to `TimeFlewApp`, so its repository name is `timeflewapp.github.io`.
